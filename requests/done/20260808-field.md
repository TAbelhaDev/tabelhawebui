# Field

> Wrapper de formulário com label e suporte a erro. Usado em toda página de form do apps/site.

- **autor**: apps/site (tabelarpgdk)
- **data**: 2026-08-08
- **prioridade**: high

## O que

Componente `Field` que envolve um label + children (input/textarea/select) + mensagem de erro opcional. Padrão em forms: login, signup, forgot-password, reset-password, criar campanha, criar sociedade.

## Por que / contexto

O apps/site tem 8+ páginas de formulário. Sem o Field, cada uma faz:

```svelte
<div class="flex flex-col gap-1">
  <label class="text-sm font-medium" style="color: var(--twui-ink);">Email</label>
  <Input type="email" name="email" />
</div>
```

Isso é repetido em login, signup, forgot-password, reset-password, verify-email, criar campanha, criar sociedade. O Field padroniza e reduz boilerplate.

## API proposta

```svelte
<script lang="ts">
  import type { Snippet } from 'svelte';

  let {
    label,
    error,
    children
  }: {
    label: string;
    error?: string;
    children: Snippet;
  } = $props();
</script>

<div class="flex flex-col gap-1">
  <label class="text-sm font-medium" style="color: var(--twui-ink);">
    {label}
  </label>
  {@render children()}
  {#if error}
    <p class="text-xs" style="color: var(--twui-danger);">{error}</p>
  {/if}
</div>
```

**Props:**

- `label` (string, required) — texto do label
- `error` (string, optional) — mensagem de erro abaixo do input
- `children` (Snippet) — o componente de input

**Exemplo de uso:**

```svelte
<Field label="Email" error={form?.errors?.email}>
  <Input type="email" name="email" required placeholder="seu@email.com" />
</Field>

<Field label="Descrição">
  <Textarea name="description" rows={3} placeholder="Descreva..." />
</Field>
```

## Escopo / fora de escopo

- dentro: wrapper simples com label + slot + erro visual
- fora: não gerencia validação, não faz layout de grid, não tem variantes de tamanho
